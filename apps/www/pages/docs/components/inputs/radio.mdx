# Overview

The `Radio` component is designed to present a set of options where users can select only one at a time. It is commonly used in forms and settings where a single choice is required from multiple options. The component ensures that only one radio button can be selected at any given time, providing a clear and intuitive user experience.

# State
The `Radio` component can be in one of the following states:
- **Default**: The radio button is unselected and ready for user interaction.
- **Disabled**: The radio button is not interactive, indicating that the option is not available for selection.

# API Reference

## Radio

A radio button component for selecting one option from a group of choices.

### Props

The `Radio` component doesn't define any custom props beyond the standard input props.

### Inherited Props

The `Radio` component accepts all standard HTML `input[type="radio"]` element props.

### Notes

- Always provide a `name` prop to group related radio buttons together
- Only one radio button with the same `name` can be selected at a time
- Use the `value` prop to distinguish between different options in the same group
